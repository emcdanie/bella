## The four breakpoints

Named by the range they describe, never Mode 1 / Mode 2. Each token names the
width where the NEXT tier begins, so `breakpoint.mobile` is the ceiling of the
mobile range, not its floor. Read the table by range, not by token name.

| Range name          | Token                  | Value  | What changes here                              |
| ------------------- | ---------------------- | ------ | ---------------------------------------------- |
| `mobile (0-639)`    | `breakpoint.mobile`    | 640px  | Single column below this width.                |
| `tablet (640-767)`  | `breakpoint.tablet`    | 768px  | Two-column grids become feasible from here.    |
| `desktop (768-1023)`| `breakpoint.desktop`   | 1024px | Standard multi-column editorial layouts.       |
| `wide (1024+)`      | `breakpoint.wide`      | 1440px | Editorial max-width and hero-scale type sizes. |

## Components do not own breakpoints

Grep the component styles and you will find no width media query. That is the
design, not an omission. A component that carries its own breakpoints decides
the layout of a page it cannot see, and then every consumer fights it.

Instead, components are intrinsically responsive:

- They fill the width they are given and let the parent decide that width.
- They wrap rather than overflow: metadata rows, tag rows and footers are flex
  containers with `flex-wrap`, so a narrow column reflows instead of clipping.
- Height is content-driven, with `height: 100%` where a grid needs equal
  siblings, so a row of cards matches without a measurement pass.
- Media wells hold an `aspect-ratio`, so a cover reserves its space before the
  image loads and the layout does not jump.

The consumer composes the grid, sets the column count at whatever breakpoint
its page needs, and BELLA fills the cells.

## The one media query components DO carry

`prefers-reduced-motion: reduce`. It is a user contract, not a layout
decision, so it belongs in the component. Five components honour it today:
Button, Card, FilterChip, SegmentedControl, and the shared Trace recipe.

Under reduced motion the travelling trace never runs, transitions and
transforms are removed, and hover falls back to a static accent ring. The
affordance survives; only the movement stops. Any new component that moves
inherits this obligation.

## Fluid type and space: not adopted

BELLA's type ramp and spacing scale are fixed steps. There is no `clamp()`
anywhere in the system, and no fluid interpolation between breakpoints.

This is a position, not an oversight. Fixed steps keep the type floors
enforceable: the gate can assert that reading text never computes below 16px
and that Unique never renders below 24px, because the values are knowable
without resolving a viewport. A fluid ramp makes those floors a function of
window width, and the floors are the accessibility bar.

If fluid type is adopted later it needs to arrive with the floors as clamp
minimums, and the gate needs to keep asserting the computed value, not the
declared one.

## Container queries: adopted for patterns (2026-09-21)

Primitives still carry none. The case this page waited for arrived with the
Work patterns: FeaturedCase puts its cover beside the body in a wide column
and above it in a narrow one, and that has to follow its own width, not the
window's, or it breaks the moment a consumer places it in a sidebar.

So each pattern in `src/patterns/`, and the layout component SectionHeader,
declares a named container
(`featured-case`, `case-grid`, `work-intro`, `before-after`, `case-meta`,
and SectionHeader's `section-header`) and queries only that. The threshold
is the `breakpoint.tablet` value, 768px, written as a literal because a
container query cannot read `var()`; each stylesheet says so next to the
query. A pattern never reads the window.

## Verifying it

`audit:visual` snapshots every story in both themes. The Storybook viewport
presets are 390 / 768 / 1240, and GATE 2 on any new component means rendering
it at every breakpoint range in both themes and actually looking, not trusting
that it fills.

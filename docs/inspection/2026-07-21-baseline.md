## The short version

BELLA is a healthy token-first system that is deliberately early on components — the token layer, testing wiring, and accessibility verification are genuinely strong for a solo practice, and most of what's yellow is either phased work already ticketed or one sync gap. The most load-bearing problem found: **`tokens/component.json` (the Tier 3 contract layer) still describes the pre-lush glass card while the shipped `Card.tsx` is the calm-at-rest `default | peek` card — and that contract layer is exactly what AI agents are told to consume.** Fix the contract-to-implementation sync (and add a mechanism that notices it) before extracting the next component, or every extraction widens the gap.

**Overall: 67/100** — a conversation starter, not a grade. No reds; no station N/I. Design-leg checks inside stations 1, 2, and 6 are N/A (Figma leg parked by decision, issue [#4](https://github.com/emcdanie/bella/issues/4)) and are recorded per-station, never silently skipped.

## Top findings, ranked by severity

1. **Tier 3 contract drift (S6, S9, S4).** `[verified]` `tokens/component.json` card entry: variants `default/elevated/glass/featured/inverse`, "glass-first" description. Shipped `src/components/Card/Card.tsx`: variants `default | peek`, calm-at-rest. The contract layer is BELLA's declared machine-readable spec for AI codegen ("a contract for AI tools generating code" — README), so this isn't cosmetic: an agent following the published contract builds the wrong card. The CI drift gate checks sources→generated artifacts only; nothing checks contracts→implementations. 8 remaining contracts will hit the same fork as extraction proceeds.
2. **No branch protection on bella main (S7).** `[verified]` via API: `protected: false`. Everything else (CI, drift gate, audits) is bypassable by a direct push — and today's work landed by direct push. ctrl-alt-design already has the pattern to copy (required `gate` check, enforce_admins).
3. **Visual regression is local-only (S5).** `[verified]` CI sets `SKIP_VISUAL_SNAPSHOTS=1`; baselines are darwin-only. Documented decision, but every token change merges with no pixel net in CI — the theme-integrity check catches polarity bugs, not regressions.
4. **No deliberate AI index; generation test never run (S9, S10).** `[verified]` Raw machine layer is strong (DTCG JSON, typed props, rule-phrased docs) but there's no llms.txt/index, and the kit's proof — hand an agent the context, have it build a composition, log the stumbles — hasn't been run. Both AI-Ready scores are capped until it is (kit rule: no test, no confirmed green).
5. **Naming has three documented escape hatches and no validator (S4).** `[verified]` `--ink-on-dark-*` governance tokens live outside the JSON scheme (issue [#3](https://github.com/emcdanie/bella/issues/3)), legacy pre-0.3 aliases are carried for the portfolio swap, `--bella-blur-*` is a namespace exception. All deliberate, all documented — but nothing machine-checks new names against the scheme, so drift accrues silently.

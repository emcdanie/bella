## The files

One generator, one fixed seed (7), so the pattern never changes between
builds. `npm run build` writes the SVG (and the gate checks it has not
drifted); `npm run build:favicons` rasterises the PNGs and packs the ICO.

## Do and don't

<DoDont
  doItems={[
    'Regenerate with the script; never edit the files by hand',

  ]}
  dontItems={[
    "Don't drop the ochre-deep edge: without it the square melts into light tabs",
    "Don't swap the letter or the ground colour",
    "Don't reroll the favicon pattern",
  ]}

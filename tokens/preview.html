Tier 3

Components

Every component reference is resolved through semantic, so flipping dark mode flips the components automatically.

Button

Keycaps with real hierarchy: an ink primary keycap, an outlined secondary, an ink text tier; one primary per view (brand refresh, 2026-09-22: no accent colour on buttons, the ochre ring means focus only). Labels are Figtree SemiBold on the label type token, sentence case, never Unique.

Variants: primary · secondary · tertiary

States: default · hover · active · focus · disabled

Use for: Hero CTA, Card 'Read more' action, Form submit, Contact send, Nav call to action (shape pill), The primary contact CTA reads "Let's talk" (brand refresh, 2026-09-22)

Don't use for: Do not render more than one primary per view: the keycap is the single 3D moment; Do not use for filters, toggles, or sort: that is FilterChip / SegmentedControl / Select territory; Do not set labels in Unique at any size; Do not build a neutral keycap: that tier is retired; Do not lift a button on hover: lift is reserved for cards; hover is the label roll; Do not add the trace ring to a button: the trace is Card's affordance

Card

The one-card system: every card surface renders through this. Calm at rest, theme-aware by construction; the only fixed-light path is Peek, on purpose.

Variants: default · peek

States: resting · hover · focus

Use for: Portfolio grid, Case-study cards, CHIP idea clusters, Dashboard tiles

Don't use for: Do not nest cards inside cards; Do not use for navigation, that's nav-link's job; Do not nest links or buttons inside an interactive card: the card is ONE link or ONE button; Do not build a fixed-dark card, no fixed-dark path exists; peek (fixed always-light paper on navy) is the one recorded fixed-context exception

ResourceCard

The folder card. A dark file window on top, a warm sheet below, and a tab folded up from the sheet itself so the two read as one piece of paper. Built for the toolkit gallery, where every item is a file you can open.

States: default · hover · focus-visible

Use for: The toolkit gallery, one card per installable skill, Any gallery where the items are files or documents with a type and a state

Don't use for: Do not put a second link inside it: the whole card is one link, the Open action is a span that inherits it; Do not give the tab its own colour or a shadow: it is the sheet folded up, and a shadow breaks the fold; Do not write the description longer than two lines: it clamps, and a clamped third line reads as a bug; Do not colour the status dot yet: the ladder is unresolved (issue #1) and the neutral dot is the honest placeholder

Tag

Non-interactive metadata. If you can click it, it is not a Tag.

Variants: default · accent

States: default

Use for: Card category labels, Project metadata rows, Mood and topic markers

Don't use for: Do not make it clickable: narrowing a set is FilterChip's job; Do not add a border: the flat wash is what separates it from interactive chips; Do not set the label in an accent or status colour: tints are wash-only here

StatusPill

A status word in a pill. Non-interactive, one tint per state, readable in both themes.

Variants: accent · success · info · neutral

States: default

Use for: Current-focus marker, Project state rows, Availability notes, neutral: a state that is neither good nor bad (not tested, draft, disabled), no tint (CHIP, 2026-10-03)

Don't use for: Do not make it clickable: a pill that toggles is a FilterChip; Do not colour the label with the state tint: the tint is border and wash only, the word carries the meaning; Do not design new status UI on the carried tints without asking: the BELLA-native status ladder (issue #1) is pending and will restyle this

FilterChip

The toggle for narrowing a set. Pressed is a real state with real semantics, not a restyle.

States: default · hover · pressed · focus

Use for: Work library skill/type filters, Any multi-select narrowing row, size compact: a long wrapping row of tag filters (CHIP Docs); the 44px target stays

Don't use for: Do not use for mutually exclusive views: that is SegmentedControl; Do not raise it: the keycap is reserved for true actions; Do not fake the state with colour alone: aria-pressed is the state, the fill is its paint

SegmentedControl

Pick one view among a few, all options visible. The selected state lives in ARIA, not just paint.

States: default · hover · selected · focus

Use for: Work library view switcher (Cards / Map / Table), Any mutually exclusive view pick with few options

Don't use for: Do not use for multi-select: that is FilterChip; Do not use radiogroup or tablist semantics: plain buttons with aria-current, per the recorded discovery pass (W3C APG radio rejected: single tab stop plus arrow-select blocks surveying; Primer SegmentedControl guidance matches); Do not hide options behind it: if they do not all fit, it is a Select

Select

For long lists only. If the options fit on screen, chips or a segmented control do it better.

States: default · focus · open

Use for: Sort order, Long single-choice lists

Don't use for: Do not hand-roll a listbox: the native select owns the popup, the keyboard model, and the assistive-tech semantics; Do not drop the visible label: an unlabelled dropdown is a guess; Do not use it for a handful of visible options: SegmentedControl or FilterChip

Heading

Figtree SemiBold 600 carries every heading tier, tight tracking, sentence case (heading weight, 2026-10-04, Elleta; was Geist Light 300). Unique is the wordmark only. Never inside a card.

Variants: hero · page · section

States: default

Use for: Page titles, Section heads, The hero headline

Don't use for: Never inside a card: cards carry titles (Figtree 600), not headings (contract-enforced by audit:quality); Never below 32px: the section tier floors at 32px; Never Unique: the wordmark is the only Unique

Icon

The only way BELLA renders an icon. Iconoir glyphs from an inlined registry, icon-token sized, always currentColor; decorative by default, a label makes it meaningful.

States: default

Use for: Segment glyphs, The Select chevron, Any leading icon slot

Don't use for: Do not put id attributes inside an icon SVG: the glyph renders more than once (the Button label roll duplicates it), so an id-referenced gradient or clip would collide; draw with paths and currentColor only (audit:quality enforces); Do not mix icon sets or draw one-off SVGs: Iconoir is the ONLY source (declared 2026-07-22) and every glyph lives in the registry, nothing inline (audit:quality enforces); Do not import an icon library component surface: the registry carries the paths BELLA ships (borrow-behavior-only, recorded); Do not hardcode an icon colour: currentColor inherits the themed ink; Do not let a meaningful icon stand without text unless its accessible name is proven in a Behavior story; decorative is the default and needs no name

Avatar

A person or entity as a circle. An image when there is one, the initials of the name when there is not, never an empty grey disc.

States: default

Use for: A portrait beside a name and role, An author or testimonial attribution, The identity slot in a contact panel

Don't use for: Do not use it as a decorative circle: an Avatar stands for someone, a plain disc is artwork; Do not ship it without a name: the initials fallback is the point, an empty disc is a bug; Do not put a status dot on it yet: the status ladder is unresolved (issue #1)

Eyebrow

Sans label above a heading, 14px, no tracking, no caps (label style; mono is for tokens, code and hashes only, Elleta, 2026-10-03). Signals context or category.

Variants: muted · ink

States: default

Use for: Above hero headlines, Above section titles, Above card groupings

Don't use for: Do not use as a heading: eyebrows complement a heading, never replace one; Never an accent colour: wayfinding is not action; Never below 13px, never tracked, never uppercased

Input

Labelled, stateful, honest about errors. The form is the channel, so the fields carry the trust.

States: default · focus · disabled · error

Use for: Contact form fields, Any labelled free-text entry; multiline renders the textarea

Don't use for: Do not use placeholder as the label: the label is always rendered and wired with for/id; Do not fake errors with colour alone: aria-invalid plus a role=alert message wired via aria-describedby is the pattern; Do not signal an error with colour alone: the danger border always comes with the WarningCircle icon, the message and aria-invalid

Link

Inline text link inside body copy: ink with an underline; hover thickens the underline; focus is the shared ochre ring (brand refresh, 2026-09-22). Visited stays ink.

States: default · hover · visited · focus

Use for: Inline references inside paragraphs, Footer links

Don't use for: Do not use for primary navigation, that's nav-link; Do not rely on color alone, always underlined or weight-shifted on hover

Nav Link

Top-level navigation item. Geist, uppercase-lite. Active state reads as text-primary with a 2px accent underline, the accent is decoration, the text carries the letters.

Variants: default · active

States: default · hover · active · focus

Use for: Top navigation bar, Footer navigation

Don't use for: Do not mix nav-link and inline-link in the same cluster; Do not color-distinguish the active state with accent-colored text, use the accent underline token instead

Section

A vertical slice of a page (layout foundation, 2026-10-03): an h2 at the one section size, an optional lede and actions, then the body. The id makes it an anchor for an On this page list, and the anchor clears a sticky header. Sections are spaced by layout.section.space on every page. The default group (padding, max-width) is the portfolio's older section box; the container now comes from layout.container.

States: default

Use for: Every block of a page below the PageHeader, Case-study sections, Health: Readiness map, Usage, Open failures, Components

Don't use for: Do not nest sections inside sections: inside a section, use Card titles; Do not leave out the heading: a block with no heading is a Columns or a Card; Do not set your own margins between sections: the section space is the rhythm

Modal

Modal dialog scaffold. Backdrop blur over the page content, centered dialog surface above.

Variants: default

States: open · closed

Use for: Dialogs, Sheets, Confirmations

Don't use for: Do not nest modals; Do not use for non-blocking UI, use a drawer or popover instead

BrandWordmark

The ELLETA / BELLA wordmark (brand refresh, 2026-09-22): custom E, L, T, A, B stroke glyphs at the locked settings (weight 12, width 58, height 130, tracking 16, soft corners; the E, A and B bars on one low line), filled with the seeded brand pattern and a grain, or in plain ink.

Variants: pattern · ink

States: default

Use for: The site nav (size nav, 40px tall), The footer sign-off (size full-bleed), The BELLA name on its own pages

Don't use for: Never below 32px tall; Never recolour the pattern: it only comes from color.pattern.*; Never as body type or a heading: it is a mark, not a typeface; Never animate it

PatternField

The brand pattern as a hero background (brand refresh, 2026-09-22): greyscale at about 7% (inverted grey at about 6% in dark) with a radial fade. Replaces the dot grid.

States: default

Use for: Behind a page opening or hero, first child of a position: relative container

Don't use for: Never behind body text at more than its token opacity; Never in colour: the colour pattern belongs to the wordmark; Never interactive

Callout

A quiet aside beside the content it qualifies (style unify, 2026-09-22, Elleta; from the reference's .note and .tbd). note: a hairline rule on the left, 13px muted text. gap: a dashed muted frame with a sans label, marking words the author still owes. Static: no interaction, no motion.

Variants: note · gap

States: default

Use for: note: a caveat or source line under a figure or section, gap: a visible placeholder for content still to be written

Don't use for: Not a status banner: no info, success, warning or error variants; Never interactive: no hover, no lift, never a link as a whole; No colour: hairline or dashed muted frame only, no chip fill, no accent; gap is a visible TODO: never ship it as finished copy

Tabs

Switch between panels that share one place on the page (CHIP components, 2026-10-03). W3C APG tabs with automatic activation; each tab owns a panel. Optional run state per tab, drawn as a dot and spoken as text.

States: default · hover · selected · focus

Use for: CHIP workspace switcher, CHIP terminal switcher (with run state), Any set of panels where one shows at a time

Don't use for: Do not use to switch a view of the same content: that is SegmentedControl; Do not use for navigation between pages: that is NavList; Do not mark the selected tab with colour alone: ink text plus the 2px ink bar; Do not render panels without tabPanelProps: aria-controls must resolve

Kbd

A keyboard shortcut in Mono keycaps (CHIP components, 2026-10-03). Semantic kbd, one recessed cap per key, with an optional spoken label for symbol keys. Static: it names keys, it does not press them.

States: default

Use for: Shortcut hint inside a search field, Shortcut legend in a help menu, Inline in body copy that names a shortcut

Don't use for: Do not make it clickable: a pressable keycap is Button; Do not raise or animate it: the raised keycap is Button's, Kbd is recessed and flat; Do not leave a symbol key unlabelled: pass label so screen readers say the shortcut, not the glyph

NavList

A sidebar of grouped links (CHIP components, 2026-10-03). Where you are is aria-current, painted as a wash plus ink plus medium weight. Optional sans group labels, counts, a footer row and a hide / show toggle.

States: default · hover · current · focus · collapsed

Use for: CHIP workspace sidebar, Any app sidebar of views or sections

Don't use for: Do not use for the site's top nav: that is the nav-link contract; Do not use for in-page panels: that is Tabs; Do not mark the current item with a wash alone: aria-current plus ink plus weight; Do not collapse without onToggle: the lists would be unreachable

Stat

One figure with its label and an optional change (CHIP components, 2026-10-03). A term-description pair: a sans label, a light display figure in tabular numerals, a change line whose direction is an arrow plus a spoken word, never colour. An optional sparkline (series, two points or more) draws the history as a 1px ink line, spoken as one sentence.

States: default

Use for: CHIP health figures (components, failures, indexed chunks, last sync), Any small row of headline figures on a Card or panel

Don't use for: Do not colour the change: up is not always good, and the status ladder has no neutral change colour; Do not invent figures: a Stat shows a real count or nothing; Do not give it its own box: place Stats on a Card or panel; Do not draw a sparkline from fewer than two real points, and never from made-up history; Do not colour the sparkline: its shape carries the trend

ScoreStrip

One system's readiness (CHIP components, 2026-10-03): an overall score with an ink bar, then one cell per station, banded sturdy (80 to 100), drifting (60 to 79) or check engine (under 60). Self-assessed stations (null) say Self-assessed in a dashed frame, never a fill. Cells carry full station names and wrap into rows; no abbreviations. Ships with ScoreLegend and scoreBand.

States: strong · mid · low · self

Use for: CHIP readiness map, fed by the station scores in bella.json, Any per-dimension score for a named system

Don't use for: Do not invent a warning colour for the mid band: it stays neutral until the status ladder adds one (issue #1); Do not show a self-assessed score as a measured number; Do not drop ScoreLegend from a map: the bands need their key; Do not rely on the wash: the edge, the figure and the spoken band carry the meaning

DataTable

Rows of facts in columns (CHIP components, 2026-10-03). Sortable headers are buttons with aria-sort, the header sticks, figures are right-aligned and tabular, and an optional single selection fills the chosen row ochre without dimming any other row.

States: default · sorted · selected · hover · focus

Use for: CHIP per-component health results, Any comparison of the same facts across many items

Don't use for: Do not dim unselected rows: selection is the ochre fill, everything else keeps its paint; Do not use ochre-deep for selection: it is the focus ring only; Do not left-align figures: numeric columns are right-aligned and tabular; Do not drop the caption: it names the table; Do not use density compact on a sortable or selectable table: interactive rows keep the 44px target (the component ignores compact there)

Drawer

A panel that slides in from the left (or the right, side=right) over a scrim (CHIP components, 2026-10-03). A native modal dialog: the page behind is inert, Esc closes it, focus returns to the trigger. For navigation on small screens.

States: closed · open · focus

Use for: CHIP sidebar below 720px, Any navigation or filter panel that cannot stay on screen at phone width

Don't use for: Do not use it as a page section: it is a modal and blocks the page; Do not open it without a visible trigger: focus has to return somewhere; Do not dim content inside the panel: the scrim covers the page, never the drawer

Combobox

One field over a grouped list (CHIP components, 2026-10-03): the ARIA combobox pattern. Typing opens the list, Up and Down move the active option while focus stays in the field, Enter chooses it, Esc closes the list. The active option is the ochre fill.

States: default · open · active-option · focus

Use for: CHIP's one input: jump to a component or doc, or ask OBI, Any field that picks from a grouped, filtered list

Don't use for: Do not move focus into the list: focus stays in the field and the active option is aria-activedescendant; Do not dim the other options: the active one gets the ochre fill, nothing else changes; Do not use it for a fixed short list without typing: that is Select

Disclosure

One open/close section (Atlas v4, 2026-10-03, Elleta: a stack of open/close sections so a card fits the screen). The header row is the whole 44px target and carries a short summary, so a closed section still says something.

States: default · hover · focus · open

Use for: Facts, Checks, Tokens and Notes on the Atlas Facts card, Any long card that should fit the screen closed

Don't use for: Do not use it for navigation or to switch views: that is Tabs or SegmentedControl; Do not hide the one thing people came for: keep the main section open by default; Do not nest a disclosure inside another

ActionChip

The quiet action (CHIP components, 2026-10-03, Elleta): a sentence-case pill for suggestions, chips and the small actions under an answer. Below secondary in weight; not a toggle and not the page's main action.

Variants: default · quiet

States: default · hover · focus · disabled

Use for: OBI suggestions and answer actions, Component chips that open Atlas, Small actions on a tile (Which have none?), quiet: an icon action beside content, such as the ⋯ visibility menu (no border at rest)

Don't use for: Do not set it in caps: sentence case is the point; Do not use it as a filter or toggle: that is FilterChip with aria-pressed; Do not use it for the main action of a view: that is Button primary

PageHeader

The top of every page (layout foundation, 2026-10-03, Elleta: one page-title size on every page, not display). A quiet meta line (breadcrumb, source or category), the page title at one fixed 40px, an optional lede held to the body measure, and an optional actions row.

States: default

Use for: The first block of every page template: Overview, Object page, Library and Settings, Atlas: the component name, its category and number as meta

Don't use for: Do not use a display Heading tier for an app page title: display is for editorial heroes; Do not put more than one keycap Button in actions: the main action only; the rest are secondary Buttons or ActionChips; Do not use it twice on a page: one h1

SidebarLayout

A sticky aside beside the content, with an optional rail on the right (layout foundation, 2026-10-03). On the 12-column grid: aside 3 and content 9, or aside 3, content 6 and rail 3. Under 1200px of its own width the rail drops under the content; under 768px everything stacks and the aside stops sticking. The aside sticks under the sticky header (--header-height) and scrolls on its own when it is taller than the screen less the header and the dock (--dock-height).

States: default

Use for: Atlas: the library beside the component, Docs: the list, the reader, the doc rail, Health: On this page, then the sections

Don't use for: Do not put the page title in the aside: the PageHeader sits in the content column; Do not add another scroll container: only the aside list, code blocks and tables scroll on their own

Columns

Two or three columns that collapse by their own width (layout foundation, 2026-10-03): three become two under 1200px and one under 768px; two become one under 768px. Even by default; split wide-start makes two columns 2:1 (a stage beside its facts). Cells stretch to the row, so cards in a row line up top and bottom.

States: default

Use for: Atlas: the specimen beside its facts (wide-start), the examples under them (even), Health stat cards

Don't use for: Do not use it for a sidebar: that is SidebarLayout; Do not nest Columns inside Columns

Slider

A native range with its value beside it and editable, the 44px target, and optional marks where a rule lives (Atlas v4, 2026-10-03, Elleta: sliders, not prop controls). The value is read out with its unit.

States: default · hover · focus · disabled

Use for: Atlas Try a change: one slider per tunable token, marks at the rules (24px WCAG 2.5.8, 44px BELLA floor), Any bounded number people tune by feel and then fine-tune by typing

Don't use for: Do not use it for a choice between a few named options: that is SegmentedControl or Select; Do not hide the number: the value always shows beside the track and can be typed; Do not put a mark without a label: a mark says which rule lives there

Tier 3

Components

Every component reference is resolved through semantic, so flipping dark mode flips the components automatically.

Button

Primary call-to-action. Iris fill with ground-colored label for primary (periwinkle fill, navy label in dark mode). Reserved for the single most important action in a view.

Variants: primary · secondary · ghost

States: default · hover · active · focus · disabled

Use for: Hero CTA, Card 'Read more' action, Form submit

Don't use for: Do not use more than one primary button per view; Do not stack two buttons of the same variant

Card

THE card (one-card system): every card surface renders through this. Calm at rest — 1px accent-tinted border, card-rest shadow; colour trace on hover/focus; media cards add a covered top with the token scrim; interactive cards are a single anchor/button with a visible focus ring and hover lift. Reduced motion swaps the trace for a static accent ring.

Variants: default · peek

States: resting · hover · focus

Use for: Portfolio grid, Case-study cards, CHIP idea clusters, Dashboard tiles

Don't use for: Do not nest cards inside cards; Do not use for navigation — that's nav-link's job; Do not nest links or buttons inside an interactive card — the card is ONE link or ONE button; Do not build a fixed-dark card — no fixed-dark path exists; peek (fixed always-light paper on navy) is the one recorded fixed-context exception

Tag

Uppercase tracked label (Geist — the mono face is retired). Categorizes a card, a project, a mood. Text-primary on a periwinkle wash is the canonical look.

Variants: accent · info · muted

States: default

Use for: Card category labels, Section eyebrows inside content areas, Filter state chips

Don't use for: Do not set foreground to iris/periwinkle/steel/sage — accent and status colors are wash and border here, never label text; Do not place on saturated backgrounds without verifying the foreground contrast

Eyebrow

Small tracked caps label above a heading (Geist; the mono token is retired and repointed). Signals context or category.

Variants: accent · muted

States: default

Use for: Above hero headlines, Above section titles, Above card groupings

Don't use for: Do not use as a heading — eyebrows complement a heading, never replace one; Do not hard-code accent color as the foreground — flow through text-accent so AAA enforcement stays centralized

Input

Text input. Geist on the card surface, warm border, iris focus ring (periwinkle in dark mode).

Variants: default · search

States: default · hover · focus · disabled · error

Use for: Forms, Search bars, Filter inputs

Don't use for: Do not strip the border on default state — it's how inputs are recognizable

Link

Inline text link inside body copy.

Variants: default

States: default · hover · visited · focus

Use for: Inline references inside paragraphs, Footer links

Don't use for: Do not use for primary navigation — that's nav-link; Do not rely on color alone — always underlined or weight-shifted on hover

Nav Link

Top-level navigation item. Geist, uppercase-lite. Active state reads as text-primary with a 2px accent underline — the accent is decoration, the text carries the letters.

Variants: default · active

States: default · hover · active · focus

Use for: Top navigation bar, Footer navigation

Don't use for: Do not mix nav-link and inline-link in the same cluster; Do not color-distinguish the active state with accent-colored text — use the accent underline token instead

Section

A vertical slice of a page. Defines standard padding and gap for content blocks.

Use for: Case-study sections, Portfolio page regions

Don't use for: Do not nest sections inside sections

Modal

Modal dialog scaffold. Backdrop blur over the page content, centered dialog surface above.

Variants: default

States: open · closed

Use for: Dialogs, Sheets, Confirmations

Don't use for: Do not nest modals; Do not use for non-blocking UI — use a drawer or popover instead

## The sync:bella consumer model

1. **Install** `bella` as a devDependency (git or `file:` while unpublished).
2. **Sync**: a `sync:bella` script copies `tokens/bella.css` from the package
   into the consumer's tree (the portfolio vendors it at `lib/bella/bella.css`)
   and records the synced version.
3. **Import once**: the vendored file is imported at the top of the consumer's
   global stylesheet, before anything that references a token.
4. **Gate**: the consumer's gate hash-checks the vendored copy against the
   installed package, so a hand-edited or stale vendored file fails CI instead
   of drifting silently. Upgrades are a sync plus a green gate, reviewed like
   any other change.

Consumers reference tokens by CSS custom property only
(`var(--color-semantic-accent)`, `var(--spacing-4)`), never by resolved value.
Dark mode activates via `data-theme="dark"` on `<html>` or `<body>`; every
semantic token flips on its own.

Rules travel with the tokens: `AGENTS.md` and `docs/RULES.md` bind consumers
too. Downstream rules may tighten BELLA's, never relax them.

## Agent access

The dev Storybook is agent-readable over MCP via `@storybook/addon-mcp`
(registered in `.storybook/main.ts`). With `npm run storybook` running, the
endpoint is `http://localhost:6006/mcp` (streamable HTTP; dev mode only, not
part of the static build). Point a client at it, for Claude Code:

```
claude mcp add --transport http bella-storybook http://localhost:6006/mcp
```

The server exposes story and documentation tools
(`get-stories-by-component`, `list-all-documentation`, `get-documentation`,
`preview-stories`, and story-writing instructions). Agents answer component
API and usage questions from these tools, not from source. The rules still
bind: `AGENTS.md` and `.microagents/` travel with the repo and outrank
anything an agent infers from a story.

## What is not here yet

No npm publication, no React package export, no Figma library sync. Components
are extracted one at a time behind the gate; until a component ships here, the
contract in `tokens/component.json` is the spec and the consumer keeps its
local implementation.

## PatternField

The pattern as a hero background: greyscale at about 7%, fading out from the
upper right, inverted grey at about 6% in dark. It replaces the dot grid.
It is decoration only: hidden from assistive tech, never interactive, never
moving.

<Canvas of={PatternStories.HeroField} />

## Seeds

The pattern is drawn from a seed. The same seed always draws the same field,
so a page looks the same on every visit.

<Canvas of={PatternStories.AnotherSeed} />
